# Protected Features — Do Not Remove

## Mobile Navigation
- Bottom nav must always show:
  - Home
  - Tasks
  - Calendar
  - More / ☰
- More / ☰ must open the hamburger menu.
- Hamburger menu must contain the secondary owner links.

## Cleaner Portal
- Cleaner Portal must remain accessible.
- Cleaner Portal mobile layout must not be cut off.
- Cleaner can view assigned reservations, mark status, and report issues.

## Reservations
- Reservations are not tasks by default.
- Reservations must show arrival and departure.
- Reservation click should open a dedicated reservation detail experience.
- Avoid using the word “turnover” in owner-facing UI.

## Task Board
- Task Board is only for items needing attention:
  - unassigned cleaner
  - maintenance issue
  - calendar conflict
  - cleaner reported issue
  - missing info
  - critical alert

## Calendar
- Only one main operational calendar system.
- Calendar should show reservations, arrivals, departures, source badges.
- Mobile calendar must stay inside a controlled scroll box.

## Properties
- Property persistence must remain.
- Property operations notes must remain.
